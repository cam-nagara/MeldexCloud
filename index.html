制作に関する情報を、つなげて管理。

Meldex BETA

Meldexは、マンガ・小説・ゲームなどの制作情報を管理するアプリです。 文書、表、マインドマップ、資料画像、Webページ、Meldex内のチャット履歴などを自動リンクでつなぎ、自動タグ付け、文章による画像検索、作品の情報を踏まえたAIとの相談などに利用できます。

Meldexの特徴

文書・表・マインドマップを作成

ノート、表、マインドマップ、スケジュールを作成できます。Webページ、資料画像、Meldex内のチャット履歴なども、関連する制作資料として管理できます。

情報同士を自動リンク

人物名や用語を文書に書くと、関連する表や資料へのリンクが自動で作られます。作品内の設定や資料を、wikiのようにたどって確認できます。

グループウェアとして使う

チャット、スケジュール、ToDo、勤怠管理などを備え、制作チームの連絡、予定、作業状況の管理や、資料の共有に使えます。

できること

作る

様々な形で、設定資料を作成したり、企画や構成を練ることができます。人物・用語・進行状況などは表で整理でき、アイデアや構成はカードを線でつないだマインドマップやハコ書きとして組み立てられます。

集める

WebページやXのブックマークを取り込み、Webページ内の画像を一括保存できます。PC内の既存フォルダも、Meldexから参照する資料の保存場所として登録できます。

整理・探す

自動リンク、全文検索、自動タグ付け、文章による画像検索、重複画像検出を使って、必要な情報を探して整理できます。

AIで活用する

保存している資料や設定をAIが参照し、相談への回答や、文書・表・マインドマップの作成・編集に利用できます。

機能の詳細を見る

メイン機能

フォルダツリー

  • ファイルとフォルダを階層表示し、作成・移動・複製をドラッグ操作で行えます。
  • 全文検索とフィルタに加え、テキストで画像を検索して絵の内容からも探せます。
  • サムネイル付き表示に対応し、画像資料も見分けやすくなっています。

フォルダパネル

  • フォルダ内のファイルをサムネイル付きで一覧表示します。
  • 重複画像の検出で、ダブって保存された画像を自動で見つけて整理できます。
  • スライドショーで、フォルダ内の画像資料を順に自動再生できます。

ノート

  • 自動リンク: シートに登録した名前を本文に書くだけで関連資料へのリンクが自動で張られ、バックリンクからつながりを辿れます。
  • Markdown形式のリッチテキスト編集。見出し・リスト・画像・コールアウト・目次を扱えます。
  • 縦書きとルビに対応。シートの「ふりがな」列に読みを登録しておくと、その名前に自動でルビが振られます。

シナリオ

  • ページ・コマ・キャラクター・セリフを表形式で整理して、話の流れを組み立てられます。キャラクター名は毎回入力せず、ドロップダウンから選べます。
  • プロットと本文を行き来しながら構成を詰められます。縦書き・ルビの表示に対応します。
  • 組み上げた内容はCLIP STUDIO PAINTへ送信でき、ネーム作業へそのまま進めます。条件付きカラーや印刷レイアウトにも対応します。

シート

  • 設定、人物、伏線、タスクなどを表形式で管理できます。
  • リレーション、ロールアップ、数式などの列を利用できます。
  • ピボット、ギャラリー、カンバン、タイムライン、チャートなどの表示に対応します。

ボード

  • カードとラインを自由に配置して、関係図・マインドマップ・伏線マップを作れます。
  • ノートやシートへのリンクカードを置けるので、全体の構成を眺めながら、カードの中身をパネルで確認できます。
  • 画像は「埋め込み」と「リンク参照」を選べます。シートやスマートシートからカードを一括取込できます。

スケジュール

  • イベント・ToDoリスト・勤怠をカレンダー形式で管理します。
  • 制作管理の「自動割り当て」で、タスクの担当者と作業予定を期間内へ自動で割り振れます。
  • Google ToDo / CalDAV など外部サービスとの同期に対応します。

スマートシート

  • 複数のシートやフォルダを横断して、条件に合うエントリだけを自動で集めます。
  • 数式・集計に対応し、ダッシュボードビューで一覧化できます。
  • 絞り込み条件を保存して、いつでも最新の結果を表示できます。

補助機能

編集パネル

  • 選択中の対象に応じて内容が自動で切り替わる編集パネルです。
  • エントリのプロパティ編集やファイルテーマの設定ができます。
  • バックリンクで、そのファイルを参照している場所を一覧できます。

ビューワー

  • 画像・動画・音声・PDF・HTMLを表示できます。
  • 表示中のファイルに注釈を書き込めます。
  • メディア一覧で、フォルダ内の画像・動画を続けて確認できます。

バージョン管理

  • ファイル・フォルダ・全体の過去の状態を、統合タイムラインで一覧します。
  • 過去の状態の閲覧・復元と、名前付きバージョンの保存ができます。
  • 自動保存された古いバージョンは段階的に間引きされ、容量を抑えます。

チャット

  • 参照中のファイルや作品の設定を文脈にして、AIへ相談できます。
  • AIは答えるだけでなく、ノート・シート・ボード・シナリオの作成や編集もできます。調査の結果を表や図の形で残せます。
  • チーム利用時は、メンバーとのメッセージ交換にも使えます。

タイマー

  • ストップウォッチ・カウントダウン・ポモドーロの3モードを備えます。
  • 通知と繰り返し設定に対応します。
  • スケジュールと連動でき、独立ウィンドウでも開けます。

操作履歴

  • 直近の操作を一覧から取り消し・やり直しできます。
  • ファイル単位の履歴も確認できます。
  • 編集中の操作の取り消しに特化し、過去の版へ戻る場合はバージョン管理と使い分けます。

注釈

  • どの画面にも手描きの線・マーカー・付箋を重ねられます。
  • スタンプ・絵文字や、色・不透明度・線幅の調整に対応します。
  • 注釈パネルで、全体の注釈を一覧して移動できます。

タグ

  • 画像の内容を解析して自動でタグを付ける「自動タグ付け」に対応します。
  • ファイルにタグを付けて、作品を横断して整理できます。
  • タグでファイルを絞り込んで探せます。

取り込み・外部連携

データの取り込み

  • Notion・Obsidian・Evernote のノートをMeldexへ取り込めます（外部サービス側は変更しません）。
  • CSV / Excel の取り込みや、画像・ファイルの貼り付けに対応します。
  • 取り込みは定期実行にも登録でき、自動で最新の状態を保てます。

X（旧Twitter）連携

  • 自分のXアカウントで認証して、ブックマークした投稿を取り込めます。差分同期で同じ投稿は増えません。
  • アカウントを指定して、そのアカウントの投稿を画像つきでまとめて取り込めます。
  • 定期実行に対応し、新しい投稿を自動で取り込み続けられます。

Meldex Web Clipper

  • ブラウザで見ているWebページ・選択範囲・画像・ブックマークをMeldexへ保存できます。
  • 「ページ内の画像を一括保存」で、ページ上の画像をまとめてダウンロードできます。
  • Chrome / Edge / Brave / Vivaldi / Opera に対応し、デスクトップ版の設定画面から準備できます。

AIツール連携（デスクトップ版）

  • Claude Code / Codex / Gemini CLI などのAI CLIから、Meldex内のノートやシートを直接読み書きできます（デスクトップ版）。
  • 手元に貯めた資料・設定・作業ログが、そのままAIの参照資料になります。
  • チャットパネルからCLIへ依頼を送り、返答をMeldexに残すこともできます。

書き出し・移行

  • Word文書・HTML・画像・CSV・ICSなど、一般的な形式への書き出しに対応します。
  • 作業フォルダはコピーして、バックアップや別環境への移行に使えます。
  • 他のツールへ移行するための手順をマニュアルで確認できます。

利用方法を選ぶ

デスクトップ版

Windows PCにダウンロードして使います。データは自分で選んだPCのフォルダへ保存されます。

  • PC内のファイルを直接扱えます。
  • PC上のAIツールやほかのソフトと連携できます。
  • インターネット接続なしでも使えます。
デスクトップ版をダウンロード

クラウド版

ブラウザで開いて使います。iPad、スマホ、Mac、Windowsに対応し、アカウント登録は不要です。

  • データは初期状態では使っている端末内に保存されます。
  • 複数端末で共有するときだけDropboxへ接続できます。

クラウド版

Meldex Cloudはブラウザですぐに使えます。アカウント登録は不要で、データは初期状態ではこの端末内に保存されます。別の端末と共有するときだけDropboxへ接続します。

クラウド版を起動

オンライン / オフラインを選べる

ブラウザでそのまま使う方法と、Meldexを端末へ保存してオフラインでも使う方法を選べます。設定は後から変更できます。

アプリのようにすぐ開く

スマホやiPadでは、Meldexをホーム画面に追加できます。追加後はホーム画面のアイコンをタップするだけで、通常のアプリと同じように開けます。

Dropboxへ切り替えても、端末内のデータが自動で移動・削除されることはありません。

必要なツールだけを単独で使う

ノート、シナリオ、ボード、シート、タイマー、クイックメモは、それぞれ単独でも利用できます。Windowsでは必要なアプリだけをダウンロードでき、スマホやiPadでは各ツールをホーム画面へ追加できます。

  • iPhone・iPadでは、各クラウド版をSafariで開き、共有メニューの「ホーム画面に追加」を選んでください。
  • Androidでは、各クラウド版をChromeで開き、ブラウザの「アプリをインストール」または「ホーム画面に追加」を選んでください。

クラウド版の制限

  • 打鍵単位のリアルタイム共同編集
  • PC内のコマンドラインツールやOSへの直接アクセス
  • ローカルCalDAVサーバーとの同期

利用前の注意

  • AI APIキーのCloud保存は、暗号化パスフレーズを忘れると復元できません。
  • AIを利用すると、質問内容と選択した資料が、使用するAIサービスへ送信されます。
  • 重要な制作データは、作業フォルダごとバックアップしてください。

利用上の注意と連絡

規約とプライバシー

利用規約 と プライバシーポリシー を確認してください。

サポートについて

Meldexは個人開発のソフトウェアです。個別の質問対応、導入支援、利用環境ごとの不具合調査などのサポートは提供していません。不具合や要望は送信できますが、返信や対応を保証するものではありません。

LLMを利用した内容

この配布ページとマニュアルは、LLMを利用して作成・更新しています。開発者がすべてのページと記述を個別に確認できていない場合があります。重要な操作や費用・外部サービス設定は、実際の画面や公式情報と照合してください。

オープンソース化と更新

Meldexは、将来オープンソースソフトウェアとして公開する予定です。公開後は、適用されるライセンスに従って修正・利用・再配布できます。開発者による更新は不定期に行われ、更新時期や継続は保証されません。

意見・不具合を記録・送信

デスクトップ版で送信先が設定済みの場合、Meldex内から報告できます。通信に失敗した報告は端末内の送信待ちに保存され、次回起動時に再送されます。送信先が未設定の場合とクラウド版では、端末内への記録のみです。
