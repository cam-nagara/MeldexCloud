Meldex BETA

Meldexは、マンガ・小説・ゲームなどの制作に関する情報を管理するアプリです。 文書、表、マインドマップ、資料画像、チャット履歴、Webページなど、さまざまな形式の情報を自動リンクでつなぎ、AIによる整理や活用ができます。 ファイルへの自動タグ付け、文章による画像検索、作品全体の情報を踏まえたAIとの相談などに利用できます。

Meldexの特徴

多くのWebアプリは、作成したデータをサービス側のクラウドへ保存します。Meldexでは、創作の材料と作業記録を自分のPCや端末内に保存します。

データはPC・端末内に保存

  • デスクトップ版は自分で選んだPCのフォルダへ、クラウド版は最初に開いた端末内へ保存します。
  • Meldexのアカウント作成や、Meldex専用クラウドへの預け入れは、使い始める条件ではありません。
  • 別の端末から同じデータを使いたい場合だけ、あとからDropboxへ接続できます。

ノートも資料もチャットも、一つの場所へ

  • 集めたWeb資料や画像だけでなく、ノート、表、マインドマップ、シナリオ、スケジュール、チャット履歴まで、同じ作品の中に置けます。
  • 同じ作品の資料と記録をまとめてAIへ渡せるため、AIが作品全体を把握したうえで返答しやすくなります。
  • 採用した案だけでなく、迷った案やボツ案も消さずに残せます。

自動リンクで設定資料を参照

  • 表で管理する人物名や用語は、ノートやシナリオに書くだけで自動リンクになります。
  • リンクをたどって、ノート、表、マインドマップ、関連する資料画像のまとまりを行き来できます。
  • リンクを個別に設定しなくても、wikiのように関連資料をたどれます。

文章や表は一般的な形式で保存・書き出しできます。バックアップと他ツールへの移行も可能です。

機能紹介

メイン機能

フォルダツリー

  • ファイルとフォルダを階層表示し、作成・移動・複製をドラッグ操作で行えます。
  • 全文検索とフィルタに加え、テキストで画像を検索して絵の内容からも探せます。
  • サムネイル付き表示に対応し、画像資料も見分けやすくなっています。

フォルダパネル

  • フォルダ内のファイルをサムネイル付きで一覧表示します。
  • 重複画像の検出で、ダブって保存された画像を自動で見つけて整理できます。
  • スライドショーで、フォルダ内の画像資料を順に自動再生できます。

ノートエディタ

  • 自動リンク: シートに登録した名前を本文に書くだけで関連資料へのリンクが自動で張られ、バックリンクからつながりを辿れます。
  • Markdown形式のリッチテキスト編集。見出し・リスト・画像・コールアウト・目次を扱えます。
  • 縦書きとルビに対応。シートの「ふりがな」列に読みを登録しておくと、その名前に自動でルビが振られます。

シナリオ

  • ページ・コマ・キャラクター・セリフを表形式で整理して、話の流れを組み立てられます。キャラクター名は毎回入力せず、ドロップダウンから選べます。
  • プロットと本文を行き来しながら構成を詰められます。縦書き・ルビの表示に対応します。
  • 組み上げた内容はCLIP STUDIO PAINTへ送信でき、ネーム作業へそのまま進めます。条件付きカラーや印刷レイアウトにも対応します。

シート

  • リレーション・ロールアップ・数式などの列タイプで、キャラ・設定・伏線・タスクを構造化できます。生年月日から年齢を求めるような数式も書けます。
  • ひとつの項目に複数の案を「採用・案・ボツ」のステータス付きで残せます。没にした案も消えず、いつでも見返せます。
  • ピボット・ギャラリー・カンバン・タイムライン・チャートの表示切り替え、画像サムネイルの拡大表示、スケジュールとの双方向同期に対応します。

ボード

  • カードとラインを自由に配置して、関係図・マインドマップ・伏線マップを作れます。
  • ノートやシートへのリンクカードを置けるので、全体の構成を眺めながら、カードの中身をパネルで確認できます。
  • 画像は「埋め込み」と「リンク参照」を選べます。シートやスマートシートからカードを一括取込できます。

スケジュール

  • イベント・ToDoリスト・勤怠をカレンダー形式で管理します。
  • 制作管理の「自動割り当て」で、タスクの担当者と作業予定を期間内へ自動で割り振れます。
  • Google ToDo / CalDAV など外部サービスとの同期に対応します。

スマートシート

  • 複数のシートやフォルダを横断して、条件に合うエントリだけを自動で集めます。
  • 数式・集計に対応し、ダッシュボードビューで一覧化できます。
  • 絞り込み条件を保存して、いつでも最新の結果を表示できます。

補助機能

オプションパネル

  • 選択中の対象に応じて内容が自動で切り替わる編集パネルです。
  • エントリのプロパティ編集やファイルテーマの設定ができます。
  • バックリンクで、そのファイルを参照している場所を一覧できます。

ビューワー

  • 画像・動画・音声・PDF・HTMLを表示できます。
  • 表示中のファイルに注釈を書き込めます。
  • メディア一覧で、フォルダ内の画像・動画を続けて確認できます。

バージョン管理

  • ファイル・フォルダ・全体の過去の状態を、統合タイムラインで一覧します。
  • 過去の状態の閲覧・復元と、名前付きバージョンの保存ができます。
  • 自動保存された古いバージョンは段階的に間引きされ、容量を抑えます。

チャット

  • 参照中のファイルや作品の設定を文脈にして、AIへ相談できます。
  • AIは答えるだけでなく、ノート・シート・ボード・シナリオの作成や編集もできます。調査の結果を表や図の形で残せます。
  • チーム利用時は、メンバーとのメッセージ交換にも使えます。

タイマー

  • ストップウォッチ・カウントダウン・ポモドーロの3モードを備えます。
  • 通知と繰り返し設定に対応します。
  • スケジュールと連動でき、独立ウィンドウでも開けます。

ヒストリー

  • 直近の操作を一覧から取り消し・やり直しできます。
  • ファイル単位の履歴も確認できます。
  • 編集中の操作の取り消しに特化し、過去の版へ戻る場合はバージョン管理と使い分けます。

注釈

  • どの画面にも手描きの線・マーカー・付箋を重ねられます。
  • スタンプ・絵文字や、色・不透明度・線幅の調整に対応します。
  • 注釈パネルで、全体の注釈を一覧して移動できます。

タグ

  • 画像の内容を解析して自動でタグを付ける「自動タグ付け」に対応します。
  • ファイルにタグを付けて、作品を横断して整理できます。
  • タグでファイルを絞り込んで探せます。

取り込み・外部連携

インポート

  • Notion・Obsidian・Evernote のノートをMeldexへ取り込めます（外部サービス側は変更しません）。
  • CSV / Excel の取り込みや、画像・ファイルの貼り付けに対応します。
  • 取り込みは定期実行にも登録でき、自動で最新の状態を保てます。

X（旧Twitter）連携

  • 自分のXアカウントで認証して、ブックマークした投稿を取り込めます。差分同期で同じ投稿は増えません。
  • アカウントを指定して、そのアカウントの投稿を画像つきでまとめて取り込めます。
  • 定期実行に対応し、新しい投稿を自動で取り込み続けられます。

Meldex Web Clipper

  • ブラウザで見ているWebページ・選択範囲・画像・ブックマークをMeldexへ保存できます。
  • 「ページ内の画像を一括保存」で、ページ上の画像をまとめてダウンロードできます。
  • Chrome / Edge / Brave / Vivaldi / Opera に対応し、デスクトップ版の設定画面から準備できます。

AIツール連携（CLI / MCP）

  • Claude Code / Codex / Gemini CLI などのAI CLIから、Meldex内のノートやシートを直接読み書きできます（デスクトップ版）。
  • 手元に貯めた資料・設定・作業ログが、そのままAIの参照資料になります。
  • チャットパネルからCLIへ依頼を送り、返答をMeldexに残すこともできます。

エクスポート・移行

  • Word文書・HTML・画像・CSV・ICSなど、一般的な形式への書き出しに対応します。
  • 作品フォルダを丸ごとコピーするだけで、バックアップや別環境への引っ越しができます。
  • 他ツールへ移行するための手順もマニュアルとして用意しています。囲い込まないことを方針にしています。

クラウド版とデスクトップ版の違い

同じ作品データを扱えますが、保存経路、速度、使える機能が違います。

デスクトップ版（ソースフォルダ：ローカル）

Windows上でMeldexを起動し、PC内のローカルフォルダをソースフォルダにします。

  • ローカル保存のため速度面で有利
  • ネットワークなしでも作業できる
  • 大きいボード、長いノート、大量のシート編集に向いている
  • 別端末との自動共有はない
  • バックアップを自分で管理する必要がある
  • PC故障時に備えた外部バックアップが必須

デスクトップ版（ソースフォルダ：同期フォルダー内）

Windows上でMeldexを起動し、Dropbox、Google Drive、OneDrive、iCloud DriveなどがPC上に作る同期フォルダー内のソースフォルダーを、ローカルファイルとして開きます。

  • PC連携やローカルファイル操作を使える
  • 読み書きはローカルファイルなのでCloud版より速い
  • 利用中のオンラインストレージを通じて複数PCとデータを共有できる
  • 同期が終わる前に別端末で開くと競合しやすい
  • 大量ファイルの初回同期には時間がかかる
  • オンラインストレージの容量と同期状態の管理が必要

クラウド版

ブラウザでMeldexを開き、初期状態ではこの端末内に保存します。必要になった時だけDropboxへ接続できます。

  • iPad、スマホ、Macでも使いやすい
  • インストール不要で使える
  • Dropboxへ接続すれば、同じDropboxを使う端末で続きから使える
  • 端末内保存だけでは別端末へ自動共有されない
  • Dropbox接続時は通信速度とDropboxの応答待ちの影響を受ける
  • PC内のコマンドラインツールやOS連携は使えない
  • オフライン利用を選べば、通信できない時もMeldex本体と端末内データを使える

デスクトップ版では、各オンラインストレージのデスクトップ同期アプリがPC上に作ったフォルダーをそのまま使えます。ブラウザ版からオンラインストレージへ直接接続する機能は現在Dropboxのみで、その他のサービスは正式版のネイティブアプリで対応する予定です。

速度比較

実測値ではなく、同じデータ量を扱ったときの一般的な体感目安です。端末性能、回線、オンラインストレージの同期状態、ファイル数で変わります。

利用形態 速度目安 読み込み/保存の特徴 向いている作業
デスクトップ版（ソースフォルダ：ローカル） 最速 PC内のファイルを直接読むため、通信待ちがありません。 大きいボード、長いノート、大量シート編集などの長時間作業。
デスクトップ版（ソースフォルダ：同期フォルダー内） 速い アプリはPC上の同期フォルダーを読み書きし、同期は各オンラインストレージのデスクトップアプリが後追いします。 Windows PCで編集し、他端末やクラウド版でも確認したい場合。
クラウド版 中〜遅い 端末内保存は通信待ちなしです。Dropbox接続時は回線とDropboxの応答待ちの影響を受けます。 iPad/スマホを含む各端末での確認、編集、外出先の追記。
  • 速度重視は「デスクトップ版（ソースフォルダ：ローカル）」、PC間共有重視は「デスクトップ版（ソースフォルダ：同期フォルダー内）」、端末自由度重視は「クラウド版」が目安です。
  • クラウド版とDropbox上のデスクトップ版を併用する場合は、保存直後に別端末で開く前に同期完了を確認してください。

クラウド版で対応

  • フォルダ、ノート、シナリオ、ボード、シート、スケジュール
  • スマートシート、クラウド版フルチャット
  • AI APIキーの暗号化Cloud保存、注釈、バージョン管理

  • シートのセル内テキスト書式とカード内書式表示

クラウド版では使えない端末連携

  • リアルタイム共同編集
  • PC内のコマンドラインツールやOS連携
  • 外部カレンダー同期リレー未設定時のGoogle / CalDAV同期

注意
