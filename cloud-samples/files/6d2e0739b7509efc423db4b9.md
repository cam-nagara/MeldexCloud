# 終章 夜明けの鬼灯

小間井芽衣は、広間の中央で背筋を伸ばした。

無表情。鉄面皮。盆を持つ手だけが、わずかに傾いている。透はもう、その危うい手元にも慣れ始めていた。

「わたくしは、小間井芽衣ではございません」

彼女はそう言ってから、少し考え、首をかしげた。

「いえ。今は、その名で通しております。現代では、そのほうが不自然が少ないかと存じました」

「十分、不自然でしたけど」

「失礼いたしました」

小間井は五十年前に鬼ヶ瀬邸で死んだメイドだった。家主の孫を装う現代名は偽装で、写真の人物は祖母ではない。彼女自身だった。

若い女中として屋敷に入り、鬼ヶ瀬家の主人の妾となり、息子を産んだ。だが家の体面、財産、正妻の嫉妬、当主の横暴が、彼女と母と子を押し潰した。名前は日記から消され、写真だけが残り、髪飾りだけが傷を覚えていた。

鬼ヶ瀬杢蔵はそのすべての直接の実行者ではない。けれど鬼ヶ瀬家の金、女、支配の論理を継いだ者だった。彼は生前、小間井を見ることができなかった。地縛霊として屋敷に残る彼女は、生者には基本的に見えない。

「死後になって初めて、旦那様にはわたくしが見えました」

小間井は鬼ヶ瀬を見た。

鬼ヶ瀬は怒鳴らなかった。金も家名も、死後の広間では何の盾にもならなかった。

「わしは……知らん。昔のことなど」

「はい。旦那様はいつも、都合の悪いことを知らないままでおられました」

平板な声だった。だからこそ、責めは重かった。

黒部は五十年前の写真を見つめた。

「つまり、芽衣さんは今回の犯人じゃない。屋敷の怨霊だけど、連続殺人は検崎さん」

「はい。わたくしは、旦那様を殺した方を見極めたかったのです」

「だから、自分も今回殺されたふりをした」

透が言うと、小間井はうなずいた。

「死霊の皆様には見えておりますので、混ざることは容易でした。生者の皆様には見えないため、わたくしの雇用実態を確かめる者もございません」

「現代家電の扱いが妙に下手だったのは」

「苦手でございます」

小間井はそこで盆を傾け、何も入っていない湯呑みをまた滑らせた。

「……こぼしました」

「それはたぶん、時代の問題だけじゃないですね」

御影が小さく笑った。泣いた後の弱い笑いだった。

検崎は広間の端で黙っていた。復讐者の顔は消え、娘を失った父親と、冤罪を作った加害者だけが残っている。成仏できるのか、消滅するのか、透にはわからない。ただ、真相から逃げる顔ではもうなかった。

薬師は検崎に向き直った。

「あなたの娘を救えなかったことは、私の中に残ります。あなたがしたことも、消えません」

検崎は低く笑った。

「先生らしいな。最後まで堅え」

「堅くなければ、折れています」

黒部は自分の仕込みについて、改めて頭を下げた。

「怪異を面白がりすぎた。死んでもまだ興奮してた。俺、本物に会いたかっただけなんだ。でも、そのせいで依ちゃんが疑われた」

御影は首を振った。

「私も、言わなかったから。お金に困ってたことも、怖かったことも、恥ずかしくて」

「交通費は大事です」

透が言うと、御影は驚いた顔をして、それから少しだけ笑った。

「そこは否定しないんですね」

「死んでも金欠はつらそうなので」

鬼ヶ瀬は羽織を握りしめていた。死霊の手では布を握れない。それでも、握ろうとする癖だけが残っている。

「わしの屋敷じゃ。わしの金じゃ。わしの」

言葉は途中で途切れた。

小間井が一歩近づいた。

「旦那様。屋敷も人も、誰か一人のものではございませんでした」

鬼ヶ瀬は何も返せなかった。

透は、これで事件が終わったのだと思った。現在の連続殺人は検崎の復讐殺人。御影の体を使った憑依犯行。検崎の先行事故死と死後首傷が決定打。小間井は今回の犯人ではなく、鬼ヶ瀬邸の原罪そのものとして残る怨霊。

真相は、死者を生き返らせない。

けれど、嘘からは解放する。

広間の輪郭が薄く揺れた。雨の音が遠くなる。死霊たちの体も、少しずつ透け方を変えていく。成仏なのか、自我の消滅なのか、まだわからない。だが少なくとも、何が起きたかを知らないまま漂う夜は終わった。

黒部は最後まで自分の手を眺めていた。

「死霊体験記、書きたかったなあ」

「死んでるので、掲載先がないですね」

「そこが最大の未練かもしれない」

御影が困ったように笑い、薬師が呆れ、検崎が短く鼻を鳴らした。鬼ヶ瀬は黙り、小間井は無表情のまま盆を抱えた。

透は肩をすくめた。

「やれやれ。死んでからのほうが、よほど忙しかった」

その言葉に、小間井が初めて、ほんの少しだけ目を細めた。

「お疲れ様でございました、狭間様」

鬼ヶ瀬邸の外では、嵐がやんでいた。

庭園の鬼灯だけが、濡れた赤い実を夜明け前の薄明かりに沈めている。屋敷の原罪は消えない。五十年前の怨みも、簡単にはほどけない。

それでも現在の事件は、終わった。

死者たちは、自分たちの死を知った。

そして透は、自分が面倒だと言い続けた真実を、最後まで見届けた。
