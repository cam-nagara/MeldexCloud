# 第二章 破れた護符

御影依を指す物証は、広間で見ただけでも十分すぎた。

袖の血。靴底の泥。破れた護符。数珠の紐についた赤黒い染み。どれも彼女の意思までは語らないが、彼女の体がどこかへ行き、何かに触れ、誰かの血を浴びたことだけは示していた。

検崎はそれを畳の上に並べるように言葉にした。

「蔵の血、書院の墨と薬品臭、居室の床板についた泥、水路の赤土。全部、この嬢ちゃんの体に乗ってる。物証は体に残る。霊だの祟りだの言う前に、そこは逃げられねえ」

「逃げられないのは物証であって、結論じゃありません」

透が返すと、検崎は片眉を上げた。

「小僧、物証を甘く見るな」

「甘くは見てません。だから分けたいんです。御影さんの体が動いたことと、御影さんが選んだことを」

御影は床に視線を落とした。気弱な彼女は、責められるたびに謝りそうになる。謝れば、それは自白に似てしまう。透はそれを止めるために先に尋ねた。

「屋敷に来た理由から、順にお願いします」

御影は小銭入れを握った。死霊の手では中身の感触はないはずなのに、癖だけが残っている。

「黒部さんに、取材の協力を頼まれました。交通費と、日当が出るって。危ない場所だとは聞いていました。でも、断ったら今月の家賃が……」

最後のほうは消え入りそうだった。

黒部は慌てて手を振った。

「依ちゃんをだましたわけじゃないよ。本物の霊感があるって聞いて、ぜひ来てほしかったんだ。もちろん安全管理は、俺のほうで」

「安全管理の結果、全員死霊ですが」

「そこは本当にごめん」

御影は夕食前から屋敷の気配がおかしかったと語った。廊下の奥から誰かに見られている感覚。大広間の天井裏で水が滴る音。家主の居室へ向かう廊下で、背中を押されるような寒気。

「護符は？」

薬師が短く聞いた。

「効いていたんです。最初は。でも、夕食の前後から、急に重くなって。誰かに呼ばれた気がして、振り返ったところから、ところどころしか覚えていません」

「疲労、低血糖、恐怖反応。そう見なすことは可能です。ですが、この破れ方は自損ではない」

薬師は破れた護符を見つめた。指で触れられないため、目だけで観察するしかない。それが彼を余計に苛立たせているようだった。

「霊媒体質に外部から強い干渉があれば、本人の意識が断続的に落ちる可能性はあります。医学だけで断じるのは不本意ですが、少なくとも単なる虚言とは言い切れない」

検崎が鼻を鳴らした。

「先生にしちゃ、ずいぶん霊に甘いな」

薬師の目が険しくなった。

「雑な断定よりはマシです。感情で死因は変わりませんし、物証の意味も変わりません」

そのやり取りに、透はわずかな引っかかりを覚えた。薬師は検崎を避ける。検崎も薬師の言葉だけは軽く受け流さず、妙に刺々しい。

黒部は自分が御影を呼んだ経緯を説明した。動画企画、鬼ヶ瀬邸の噂、五十年前の女中の怨霊、鬼灯の庭。彼は言いながら興奮し、死霊になった感動まで混ぜて話を広げた。

「黒部さん、今は企画書じゃなくて証言を」

「そうだった。ごめん、死後初取材でテンションが」

黒部の話には、意図的に抜けている部分があった。彼は屋敷内に仕込みをしている。けれどこの段階では、そこへ触れられたくない様子だった。

小間井は壁際で盆を持ったまま立っていた。御影を見ているようで、実際には全員の反応を見ている。透が視線を向けると、彼女は無表情に言った。

「依様は、何度かお一人で廊下に立っておられました」

「見たんですか」

「はい。ですが、呼びかけても返事はございませんでした」

「いつ」

「夕食の後。詳しい時刻は、時計が止まっておりましたので」

重要な証言なのに、小間井の語りは平板だった。しかも、彼女が生前の屋敷で本当に見えていたのかどうかは、まだ誰にも確認できていない。

鬼ヶ瀬は御影を睨み、鼻で笑った。

「巫女の娘など信用ならん。金に困っとる者は、いくらでも悪さをする」

御影の肩が縮こまる。

透は鬼ヶ瀬を見た。

「金に困っているから悪い、という理屈なら、この屋敷の主人はかなり怪しいですね」

鬼ヶ瀬が怒鳴った。検崎が間に入り、また場を乱すような冗談を飛ばした。だが透は、場が乱れるほど御影犯人説だけが真ん中に残ることに気づいていた。

検崎は物証を強調する。御影は気弱で否定しきれない。黒部は自分の仕込みを隠している。薬師は医学的補足をしながら検崎との過去を伏せる。小間井は見ているのに決定打を出さない。鬼ヶ瀬は金と偏見で御影を責める。

誰も完全には嘘をついていない。だからこそ、全体が御影へ傾く。

「御影さん」

透は静かに聞いた。

「記憶が途切れる直前、何か聞こえませんでしたか。声じゃなくてもいい。気配でも、音でも」

御影は両手で護符袋を包んだ。しばらく黙ってから、唇を震わせた。

「誰かに、呼び止められた気がします。名前じゃなくて、もっと近くに来いっていう感じで。振り向いたら、水の匂いがして……それから、わかりません」

水の匂い。

透は水路の暗さを思い出しかけた。自分の最後の記憶も、そこにある。

「御影さんの体は、現場を歩いている。でもその体を呼んだ何かがいる」

検崎は腕を組んだ。

「何か、じゃ捜査にならねえ」

「だから、人に戻すんです。何か、じゃなくて、誰かに」

透は御影の靴底の泥を見た。雨の泥ではない。水路から来た泥だ。

誰かが御影の体を水路へ呼んだ。そこに、すべての順序の歪みがある。
