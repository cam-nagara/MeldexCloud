# 第一章 雨夜の鬼ヶ瀬邸

狭間透が目を開けたとき、最初に見えたのは畳の縁だった。

頬が畳に触れている感覚はない。手をつこうとして、指先が床をすり抜けた。透は反射的に身を起こし、それから自分の腕の向こう側に畳目が透けて見えることに気づいた。

「……やれやれ。寝起きに見る夢としては、だいぶ趣味が悪いな」

声は出た。けれど喉が震えた感覚は薄い。息を吸っても胸は広がらず、寒さも湿気も、記憶の中にあるものをなぞるようにしか感じられなかった。

鬼ヶ瀬邸の大広間には、透のほかに六人がいた。

黒部録郎は、自分の手を光にかざして泣いていた。泣いているのに顔は笑っている。四十四歳のオカルトライターは、透けた指の間から襖の桟が見えるたびに、肩を震わせた。

「本物だよこれ！　透くん、見てくれ、俺たち、本当に死霊だ！」

「喜ぶところですか、それ」

「死霊になれた……ありがとう世界……」

黒部の感涙は本物だった。被害者らしい震えはどこにもない。死後すぐの人間としてはあまりに明るく、オカルトオタクとしてはあまりに正しい反応だった。

御影依は広間の隅で膝を抱えていた。肩口で切りそろえた黒髪が頬に貼りつき、護符袋の紐が切れかけている。袖口には乾いた血の黒ずみ、靴底には赤土と水路の泥が固まっていた。

「私じゃありません」

彼女はそれだけを繰り返していた。声は細く、けれど否定だけは必死だった。

検崎甚一が大きな足音のつもりで畳を踏み鳴らした。死霊だから音はほとんど鳴らない。それでも、くたびれたスーツの刑事は場を仕切る勢いだけで空気を揺らした。

「落ち着け。物証はブッショー面してても嘘はつかねえ。まずは現場、次に証言だ」

「今ので空気が落ち着いた人がいたら、見てみたいですね」

透の皮肉を、検崎は豪快に笑って受け流した。だが御影の袖の血を見る目だけは、笑っていなかった。刑事の目だった。

薬師治彦は細い黒縁眼鏡を押し上げ、広間の死者たちを順に観察した。落ち着いたジャケットに薬品ケース。死んでいるという事実に対しても、彼は苛立ちを混ぜた理論で距離を取ろうとしていた。

「死霊という呼称は不正確ですが、現象としては共有幻覚ではない。全員が同一の相手を認識している。問題は、物理干渉が可能かどうかです」

薬師は近くの湯呑みに手を伸ばした。指は陶器の中を通り抜けた。

「不可能ですね。少なくとも通常の接触は」

鬼ヶ瀬杢蔵は座布団の上でふんぞり返っていた。白髪の乱れた老当主は、死後でも当主の顔をやめない。家紋入りの羽織を揺らし、広間を見回して怒鳴った。

「わしの屋敷で勝手をするな。誰が死んだなどと騒ぎ立てる。金を出しとるのはわしじゃ」

「死んだ後も会計の心配ですか」

「坊主、口の利き方に気をつけい」

小間井芽衣はその鬼ヶ瀬の背後で、盆を持って無表情に立っていた。若いメイド姿。現代的な名に反して所作は古く、盆の角度だけが妙に危うい。

「皆様、お茶を」

盆の上の湯呑みは傾き、茶は畳にこぼれず空中を落ちて消えた。小間井は一拍遅れて、表情を変えずに頭を下げた。

「失礼いたしました。こぼしました」

「死霊にお茶を出す意味はあるんですか」

「問題ございません」

「今、問題しかなかった気がしますけど」

小間井は自分も被害者だと名乗った。鬼ヶ瀬家の孫を装って住み込みで働いていた、と。だが鬼ヶ瀬は彼女を見るたび、現在ではないどこかを見ているように目を細めた。

透は全員の顔を見た。黒部、御影、検崎、薬師、鬼ヶ瀬、小間井。そして自分。全員が死者で、全員が死の瞬間を覚えていない。

黒部は蔵で殺されたらしい。薬師は書院で倒れていた記憶がある。鬼ヶ瀬は居室で誰かに迫られたところまで。御影は意識が途切れ、目覚めたときには水の冷たさだけが残っていた。検崎は自分も被害者だと言い、首の傷を指した。透は水路の縁、月明かり、誰かの影を思い出しかけて、その先だけが抜け落ちていた。

「死んだ瞬間だけ、みんな覚えていない」

透が口にすると、広間は静かになった。

「なら、犯人を本人に聞けば終わり、とはいかないわけだ。しかも死霊は物に触れない。証拠も動かせない。鑑識も来ない。成仏の条件は真相の受け入れ。……面倒なことになったな」

検崎が御影を見た。

「面倒でも、筋は通す。霊能力者の体に血と泥がある。複数現場に出入りした跡だ。まずはそこからだ」

御影は青ざめ、護符袋を握りしめた。

「違います。私、本当に、覚えてなくて」

「覚えてねえことと、やってねえことは別だ」

検崎の言葉は乱暴だったが、物証だけを見れば正しいように聞こえた。

透は御影の袖、靴底、破れた護符を見た。証拠は彼女の体を指している。だが彼女の目は、自分の罪を隠す目ではなく、自分の体に裏切られた者の目だった。

「体が現場にいたことと、本人がやったことは同じじゃない」

透は立ち上がった。立ち上がる足に重みはない。それでも、広間の全員がこちらを見た。

「順番を戻しましょう。誰が、いつ、どこで死んだのか。そこからです。全員同時に死んだわけじゃないなら、まだ何か見える」

黒部が涙を拭いながらうなずいた。御影は震えたまま顔を上げた。薬師は不満げに眼鏡を押し上げた。鬼ヶ瀬は鼻を鳴らし、小間井は盆をまっすぐ持ち直した。

検崎だけが、ほんの一瞬、笑みを消した。

透はその沈黙を見逃さなかった。
