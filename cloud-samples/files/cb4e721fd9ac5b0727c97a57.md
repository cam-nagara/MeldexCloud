## コンセプト

### 死んでからが、本番だ。

嵐に閉ざされた湖畔の旧家、**鬼ヶ瀬邸**。
取材のために集まった者たちは、一夜のうちに次々と殺される。
最後に死んだ高校生探偵・**[狭間 透](サンプル/死霊探偵/キャラ表/狭間 透.md)**が目を覚ますと、そこにいるのは自分を含めた死霊たちだった。

死霊たちの目的はひとつ。
自分たちの死の真相を受け入れ、成仏すること。

ただし事件は単純ではない。
物理的な証拠は、気弱で金欠の霊能力者・**[御影 依](サンプル/死霊探偵/キャラ表/御影 依.md)**を指している。
彼女の体が実際に犯行現場を歩き、血を浴び、逃げているからだ。

しかし依は犯人ではない。
彼女の体を使っていたのは、17時台に自分の罠で事故死し、死霊となった刑事・**[検崎 甚一](サンプル/死霊探偵/キャラ表/検崎 甚一.md)**だった。
検崎は死後、依に憑依し、復讐のために殺人を続けた。

「犯人は死者の中にいる」だけではない。
**犯人は、殺人が始まる前から死者だった。**

### セールスポイント

1. **全員死亡後から始まる逆算ミステリー**
   - 探偵も容疑者も被害者も死霊。
   - 死後の証言と生前の行動表を照合し、死亡順序を復元する。
   - 「死の瞬間だけ記憶がない」ルールが、犯人にも適用される。

2. **憑依による二重犯人構造**
   - 物証上の犯人は御影依。
   - 意志決定者は検崎甚一の死霊。
   - 「体の犯人」と「意志の犯人」がずれるため、フェアな推理と怪異ギミックが両立する。

3. **コメディで読ませる本格ロジック**
   - 狭間透のヤレヤレ系ツッコミ。
   - 黒部録郎の死霊化感涙オタク反応。
   - 検崎甚一の豪快なオヤジギャグと迷推理。
   - 小間井芽衣の無表情ドジっ子メイド感。
   - 軽い掛け合いの裏で、死体損壊・死亡順序・憑依痕跡を積み上げる。

4. **屋敷因縁と現代復讐の二層構造**
   - 表の事件: 検崎の娘の死をめぐる復讐殺人。
   - 裏の因縁: 鬼ヶ瀬家が五十年前に生んだメイド怨霊の悲劇。
   - 小間井芽衣は今回の真犯人ではないが、屋敷そのものの罪を体現する。

## 舞台設定

### 鬼ヶ瀬邸

**所在地**: 某県山奥の湖畔に建つ旧家の屋敷。
周囲は深い山林と湖に囲まれ、唯一の橋は嵐で不通になる。
連絡手段は断たれ、外部の警察・救急・鑑識は入れない。

**建物**:

- **本館** : [大広間](サンプル/死霊探偵/場所情報/大広間.md) 、 [客間](サンプル/死霊探偵/場所情報/客間.md) 、 [書院・資料室](サンプル/死霊探偵/場所情報/書院・資料室.md) 、 [家主の居室](サンプル/死霊探偵/場所情報/家主の居室.md) 、 [仏間](サンプル/死霊探偵/場所情報/仏間.md) 。
- **離れ** : 茶室と [客間](サンプル/死霊探偵/場所情報/客間.md) 。 [渡り廊下](サンプル/死霊探偵/場所情報/渡り廊下.md) で本館とつながる。
- **蔵** : 古文書蔵と道具蔵。黒部のヤラセ装置や事件道具が絡む。
- **庭園** : 鬼灯の群生地、池、朱塗りの太鼓橋。
- **[地下通路](サンプル/死霊探偵/場所情報/地下通路.md)** : [古い屋敷図面](サンプル/死霊探偵/アイテム表/古い屋敷図面.md) と [錆びた地下鍵](サンプル/死霊探偵/アイテム表/錆びた地下鍵.md) が手がかりになる。
- **[水路・崖沿い](サンプル/死霊探偵/場所情報/水路・崖沿い.md)** : 検崎の事故死、霊能力者の強制自殺、主人公殺害、死体偽装が集中する最重要地点。

**雰囲気**:

- 障子越しの影、襖の向こうの声、 [渡り廊下](サンプル/死霊探偵/場所情報/渡り廊下.md) の足音で「そこにいる」と錯覚させる。
- 生者には見えない小間井芽衣が、全員死霊化後には自然に混ざる。
- 古い屋敷の因縁と、現代の取材・配信・捜査資料が衝突する。

## 死霊と憑依のルール

| ルール | 内容 |
| --- | --- |
| **死霊同士は見え、会話できる** | 死後の捜査パートでは全員が互いを認識できる。 |
| **生者には基本的に死霊が見えない** | 生前の鬼ヶ瀬杢蔵には小間井芽衣が見えていない。死後に初めて認識する。 |
| **死霊は物理干渉できない** | 直接の殺人・証拠操作はできない。物理干渉には生者の体が必要。 |
| **御影依は憑依されやすい** | 霊媒体質のため、死霊が一時的に体を使える。依本人の記憶は途切れる。 |
| **憑依中の体には物証が残る** | 血、泥、移動痕跡、目撃証言は依を指すため、冤罪構造が成立する。 |
| **殺された瞬間の記憶がない** | 被害者は自分の死の瞬間だけ欠落する。検崎も事故死の瞬間を覚えていない。 |
| **記憶は時間経過で薄れる** | 七日程度で自我が消える。推理のタイムリミットになる。 |
| **霊能力は解決のショートカットにしない** | 怪異は犯行手段・制約・ミスリードとして使う。真相証明は証言・時系列・物証で行う。 |

### 決定的な証明軸

1. **死亡順序の再解釈**
   - 検崎は殺された被害者ではなく、17時台に事故死している。
   - 23時台の首傷は死後につけられた傷であり、薬師の医学的知見が決め手になる。

2. **御影依の冤罪構造**
   - 物証は依の体を指す。
   - ただし依本人の意志では説明できない行動、知識、手際が混じる。
   - 憑依中の癖・言葉・現場選択が検崎のものとしてつながる。

3. **検崎の口滑り**
   - 死霊として、また憑依中の体として見聞きした情報を前提に話してしまう。
   - 「なぜあなたがそれを知っている？」という形で、死後犯行が露呈する。

4. **小間井芽衣の正体と切り分け**
   - 小間井は最初から屋敷にいる怨霊。
   - 彼女の嘘は「自分も今回殺された」という身分偽装であり、連続殺人の実行ではない。
   - 生前の杢蔵には見えていなかったため、目撃証言の矛盾は死後視点・過去記憶・怨霊認識のズレとして整理する。

## 物語構成

### 第一幕「全員、死んでいる」

- 狭間透が目覚め、自分の体が透けていることに気づく。
- 屋敷内で黒部、薬師、鬼ヶ瀬、御影、検崎、小間井と出会う。
- 黒部は死霊になれたことに感涙し、検崎は豪快に仕切り、薬師は死霊状態を医学的に分析しようとする。
- 御影は「私じゃありません」と怯え、物証は彼女を指す。
- 小間井は無表情に茶をこぼしながら、自分も被害者の一人だと名乗る。
- 透は「全員同時に死んだ」のではなく、死亡順序があると気づく。

### 第二幕「死者の証言」

- 各人の最後の記憶を集める。
- 黒部のヤラセ装置が怪現象と犯行手段を混線させる。
- 薬師は死因の推定を行うが、自分の死と検崎の死体には感情的な抵抗を見せる。
- 鬼ヶ瀬の記憶混濁により、小間井の古い本名や五十年前の事件が断片的に漏れる。
- 検崎は「物証が御影を指す」と強く主張し、迷推理とオヤジギャグで場を荒らす。
- 御影の気弱さと金欠事情が明らかになり、黙っていたことが疑いを深める。

### 第三幕「憑依の逆算」

- 透は、御影の体が犯行現場にいたことと、御影本人の意志では説明できない行動を分けて考える。
- 憑依中の癖、現場選択、刑事だけが知る捜査情報が検崎へつながる。
- 薬師の医学的推定から、検崎の首傷が死後損傷だと分かる。
- 検崎は「自分も殺された被害者」という前提を崩される。
- 読者への挑戦を挟み、すべての手がかりが出そろった状態にする。

### 第四幕「真犯人は先に死んでいた」

- 透が死亡順序を再構成する。
- 検崎は17時台に事故死し、18時台に御影へ憑依、20時以降の殺人を実行した。
- 娘の死への復讐が動機だったが、職務にマジメだった刑事が、復讐のために別の被害者を作った事実を突きつけられる。
- 御影の冤罪が晴れる。
- 小間井は自分が五十年前の怨霊であり、今回の連続殺人犯ではないと明かす。
- 事件解決後、死霊たちは真実を受け入れ、それぞれの未練と向き合う。

## ミステリーとしてのフェアプレイ方針

| 方針 | 内容 |
| --- | --- |
| **霊能力で解決しない** | 霊能力は犯行手段と制約に使う。真相証明は時系列、死因、証言矛盾で行う。 |
| **物証は嘘をつかないが、解釈は誤れる** | 物証が御影の体を指すこと自体は正しい。間違いは「御影本人の意志」と解釈する点。 |
| **犯人は登場人物の中にいる** | 真犯人は検崎甚一。未登場人物や屋敷外の第三者にはしない。 |
| **死因・死後損傷は医学的に扱う** | 薬師の知識で、検崎の首傷が後付けであることを示す。 |

## テーマ

> 死んでもなお、人は真実を求める。

死後だから嘘がなくなるわけではない。
死者はなお、秘密を守り、罪を隠し、誰かを庇い、誰かを恨む。

だからこそ、真実を明らかにすることには意味がある。
狭間透にとって、この事件は自分の死すら含めた最後の推理であり、御影依にとっては自分の体が背負わされた罪を取り戻す戦いである。

検崎甚一にとっては、復讐と職務の矛盾を突きつけられる裁き。
小間井芽衣にとっては、五十年前の怨みと今回の殺人を切り分けるための区切り。

真相は死者を救うだけではない。
死者が死者のまま、嘘から解放されるための手続きになる。

## 制作メモ

- 企画書上の正式な主要人物は、狭間透、御影依、検崎甚一、黒部録郎、薬師治彦、鬼ヶ瀬杢蔵、小間井芽衣の7名に統一する。
- 屋敷名は **鬼ヶ瀬邸** を基本にする。庭園の鬼灯群生地は雰囲気要素として残してよい。
- 小間井芽衣は「家主の孫を装う現代名」。本名や五十年前の旧名は、必要になった段階で別管理する。
- 生前の鬼ヶ瀬杢蔵には小間井芽衣が見えていない。杢蔵の発言は、死後認識・過去記憶・記憶混濁として処理する。
- 御影依は犯行の器だが、意志としての犯人ではない。物証と意志の分離を徹底する。
- 検崎甚一は豪快でバカっぽいが、職務に関わる部分だけはマジメ。この落差を真犯人の違和感として使う。
- 黒部録郎のヤラセ装置は、怪異否定のギャグではなく、真相を一段誤読させるための物証ミスリードにする。
- 薬師治彦の医学知識は正しい。間違える場合は知識ではなく、本人の怒り・罪悪感・検崎回避が原因になる。
- 第一話の引きは「全員死んでいる」だが、真相構造は「全員が同時に死んだわけではない」。死亡順序の復元を中核に置く。
- 読者への挑戦前には、検崎の事故死時刻、首傷の死後損傷、御影の記憶欠落、憑依中の癖、小間井の生前不可視性を提示済みにする。
