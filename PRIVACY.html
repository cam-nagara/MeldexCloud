プライバシーポリシー

Meldexで作成した作品・データがどこに保存され、どの操作で外部サービスへ送信される可能性があるかを説明します。

  • 最終更新日: 2026-05-10
  • 配布者: cam-nagara / Meldex 開発者
  • 問い合わせ: GitHub Issues または配布ページ記載の連絡先

要点

  • 作品・データはユーザーに帰属します。Meldex開発者は、ユーザーの作品・データに所有権を主張しません。
  • 作品データは原則としてユーザー側に保存されます。ローカルPC、またはユーザー自身が指定したDropboxなどのクラウドストレージに保存されます。
  • テレメトリは任意です。クラッシュレポートや匿名利用統計は、ユーザーが同意した場合だけ送信されます。
  • LLM連携では外部プロバイダへ送信されます。質問本文、選択した関連コンテキスト、添付内容は、ユーザー自身のAPIキーで各LLMプロバイダへ送信されます。

作品・データの帰属と保存場所

ユーザーがMeldexで作成・編集した作品・データはユーザー自身に帰属します。Meldex開発者は、ユーザーの作品・データに対して所有権を主張しません。

作品・データは原則としてユーザーのローカルPC上、またはユーザー自身が指定したクラウドストレージに保存されます。Meldex開発者のサーバには保存されません。

テレメトリとクラッシュレポート

Meldexは、ユーザーが明示的に同意した場合に限り、クラッシュレポートと匿名利用統計を送信することがあります。

送信される可能性がある情報

  • スタックトレース
  • OSバージョン、Meldexバージョン
  • 直前操作の概要
  • 機能利用頻度、パフォーマンスメトリクス
送信対象に含めないもの: 作品本文、作品ファイル名、現在開いている作品パス、ユーザー識別情報、LLM APIキーは送信対象に含めません。ユーザーが同意するまで、テレメトリは送信されません。同意は設定画面から後で変更できます。

LLM連携時の外部送信

ユーザーがチャット機能などのLLM連携を使う場合、質問本文、ユーザーが選択した関連コンテキスト、添付したファイル内容は、ユーザーが設定したAPIキーに基づきOpenAI、Anthropic、Google Geminiなどの外部LLMプロバイダへ送信されます。

Meldex開発者はその送信内容を取得・閲覧・保存しません。送信はユーザー本人のAPIキーで直接行われ、Meldex開発者のサーバを経由しません。

  • APIキーが未設定のプロバイダには送信されません。

Dropboxなどの同期サービス

ユーザーがDropboxなどのクラウドストレージ内にMeldexのソースフォルダを置いた場合、作品・データ、ゴミ箱（_trash/）配下のファイル、設定ファイルがそのサービスの同期対象になります。

Dropbox接続中は、同じDropboxアカウントで使う端末間のプロフィール同期のため、Dropboxの accountId、ユーザー名、ユーザーアイコン、アイコン背景色がDropbox内の MeldexSettings/_meldex/profiles.v1.json に保存されることがあります。

LLM APIキーをクラウド保存する場合、APIキーはユーザーが設定したパスフレーズで暗号化され、Dropbox内の _meldex/secrets/llm-api-keys.v1.json に保存されます。Meldex開発者は復号用パスフレーズを取得しません。

クラウドストレージ側で削除・巻き戻しを行った場合、Meldex側でも影響を受けることがあります。

第三者ライブラリと変更

Meldexは第三者ライブラリとフォントを同梱します。ライセンス情報は THIRD-PARTY.md と CREDITS.md を参照してください。

本ポリシーは、機能追加や配布方法の変更に応じて更新される場合があります。
